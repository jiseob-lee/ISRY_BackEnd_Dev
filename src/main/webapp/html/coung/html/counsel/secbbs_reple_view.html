댓글상담실 이용 시 주의사항

  • 욕설, 비방, 고민과 관령 없는 글, 특정한 의도성이 있는 것으로 판단되는 경우 등은 관리자에 의해 무통보 삭제 처리됩니다.
  • 위기(자살, 폭력, 임신) 상담이나 비공개 상담은 1:1 채팅상담, 비밀게시판을 이용해주세요.
  • 24시간 전화상담은 이겨번호 +1388 / 24시간 자살위기 전화상담은 1577-0199
  • 댓글 게시판은 150자 미만의 짧은 고민을 쓰는 곳으로, 150자 이상의 고민은 1:1 채팅상담이나 비밀게시판을 이용해주세요.
  • 문의사항은 '고객의 소리'에 글을 남겨주세요. 페이지 하단 '고객의 소리'버튼을 클릭하면 이용하실 수 있습니다.
