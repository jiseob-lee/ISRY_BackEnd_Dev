고민이 있나요?
나와 비슷한 고민사례를 읽어보고, 심리건강 정보도 받아보세요.

고민해결백과 상담자답변 이용안내

  • 고민해결백과 주제(상담주제)를 선택 후, 댓글상담 등록 시 입력했떤 닉네임, 이메일, 비밀번호를 입력해야 댓글상담에 대한 상담자의 답변을 볼 수 있습니다.
  • 청소년 사이버상담센터의 모든 상담내용 및 콘텐츠를 사용할 경우
    • 청소년 사이버상담센터 동의 없이 배포하거나 공개할 경우 법적인 책임을 질수 있음(저작권법 제2조, 9조등)
    • 상담내역 제출이 필요할 경우 반드시 청소년사이버상담센터(051-662-3066)로 문의 후 동의절차를 거쳐야 함.
  • 상담답변을 확인할 수 없을 때
    「고객의 소리」 게시판에 작성일, 작성자명, 글 제목, 글 내용 등에 대한 정보를 남겨주시면 도움을 드리겠습니다.
  • 게시판 상담의 모든 내용은 비밀이 보장됩니다.
