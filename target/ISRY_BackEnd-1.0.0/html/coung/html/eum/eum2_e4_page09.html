Action Plan! (활동 계획)

영상 하나를 보시겠습니다.
모두들 잘 알고 있는 영화감독, 스티븐 스필버그의 이야기입니다.

영상을 보고 난 뒤 어떤 마음이 드셨나요?

지금은 우리 아이와 부모님 앞에 있는 문제가 너무도 크고 어려워 보일 수 있고 막막한 마음이 드실 수도 있습니다. 하지만 이렇게 부모교육에 참여하고 노력하시는 부모님이 옆에 있다면, 우리 아이들도 스필버그처럼 위기를 기회로 삼아서 더 크게 성장할 수 있답니다.
