나와 자녀의 관계는?

나는 어떤 유형의 부모인지 알아보기 위해 부모양육태도 검사*를 실시해보겠습니다.
주어진 각각의 상황에서 내가 어떤 반응을 보이는지 해당하는 항목에 클릭해주세요.
*출처 : 이희경(2006). 똑똑한 아이로 키우는 부모들의 대화기술. 서울: 산호와 진주. p. 8~19.

시어머님(장모님)께서 먹으라고 허락한다면?

상황 #03

당신의 아이가 화장품, 휴지 등을 뒤집어엎어 온 방안에 어지럽게 해 놓았다면?

상황 #04

아이가 당신이 아끼던 꽃병을 깨놓고선 옆집 친구가 그랬다고 거짓말을 했다면?

상황 #05

상황 #06

상황 #07

당신의 아이가 학교(유치원)에서 내준 숙제를 이번에도 또 잊고 안 해 간다면?

상황 #08

상황 #09

상황 #10

당신의 기분이 언짢은데 자녀가 당신의 관심을 받고자 보챈다면?

상황 #11

당신의 아이가 블록 쌓기 놀이를 하는데 원하는 대로 잘 되지 않아서 짜증을 부린다면?

상황 #12

당신의 집에는 자녀가 지켜야 할 규칙이 얼마나 많습니까?

상황 #13

당신이 좋아하는 음식을 특별히 준비하였는데 아이가 먹기 싫다고 한다면?

상황 #14

자야 할 시간이 훨씬 지났는데도 아이가 하고 있던 놀이를 더 하고 자겠다고 고집을 피운다면?

상황 #15

상황 #16

상황 #17

당신은 얼마나 자주 자녀에게 화를 냅니까?

상황 #18
