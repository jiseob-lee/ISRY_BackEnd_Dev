자녀에게 이혼사실 알리기

자녀들에게 이혼에 대해 말하기가 난감해서 얘기할 시간을 놓치거나 둘러댄다면 자녀들은 부모의 이혼에 대해 잘못된 개념을 갖게 될 수 있습니다. 유기불안이나 재결합에 대한 환상 등을 가져 현실적응에 어려움을 겪을 수도 있게 됩니다.
자녀의 정서나 적응문제를 예방하기 위해 이혼에 대해 명확하게 설명해주는 것은 중요한 과정입니다.

올바르지 않은 방법으로 이혼사실을 알았을 때 자녀의 반응을 살펴보겠습니다.

올바르지 않은 방식으로 자녀에게 이혼 사실을 전달되어 자녀들이 느끼는 감정을 보고 어떤 느낌이 드셨나요? 자녀들이 짐작으로만 생각하게 되고 우울과 불안한 감정이 들게 만드는 모습으로 보여 집니다.
